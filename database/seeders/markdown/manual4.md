## 1. Что такое CSS

**CSS (Cascading Style Sheets, каскадные таблицы стилей)** — это язык стилей, используемый для описания внешнего вида документа, написанного с помощью HTML или XML.


**Основные задачи CSS:**
* оформление текста (шрифты, цвета, размеры);
* расположение элементов на странице (вёрстка);
* создание визуальных эффектов (тени, скругления, анимации);
* адаптация дизайна под разные устройства (адаптивный дизайн).

## 2. Способы подключения CSS к HTML

### 2.1. Внутренние стили (inline)

Стили прописываются прямо в HTML‑тегах через атрибут `style`.

**Пример:**
```html
<p style="color: red; font-size: 16px;">Красный текст 16 px</p>
```

**Плюсы:** быстрый способ для тестирования.
**Минусы:** не масштабируется, смешивание разметки и стилей.

### 2.2. Внутренние стили в `<head>`

Стили помещаются внутри тега `<style>` в секции `<head>`.

**Пример:**
```html
<head>
  <style>
    p { color: blue; font-size: 14px; }
  </style>
</head>
```

**Плюсы:** все стили в одном месте для одной страницы.
**Минусы:** нельзя использовать на других страницах.

### 2.3. Внешние стили (рекомендуемый способ)

Стили хранятся в отдельном файле с расширением `.css` и подключаются через тег `<link>`.

**Пример подключения:**
```html
<head>
  <link rel="stylesheet" href="styles.css">
</head>
```

**Файл `styles.css`:**
```css
p {
  color: green;
  font-size: 18px;
}
```

**Плюсы:** повторное использование, лёгкое обновление, разделение кода.
**Минусы:** дополнительный HTTP‑запрос.

## 3. Синтаксис CSS

Базовая структура правила CSS:
```css
селектор {
  свойство: значение;
  свойство: значение;
}
```

**Пример:**
```css
h1 {
  color: #333;
  font-family: Arial, sans-serif;
}
```

## 4. Основные селекторы CSS

### 4.1. По тегу
```css
p { color: black; } /* все абзацы */
```

### 4.2. По классу
```css
.highlight { background-color: yellow; } /* элементы с class="highlight" */
```

### 4.3. По ID
```css
#header { width: 100%; } /* элемент с id="header" */
```

### 4.4. Составные селекторы
```css
div p { color: gray; } /* абзацы внутри div */
.menu a { text-decoration: none; } /* ссылки внутри элемента с class="menu" */
```

## 5. Основные свойства CSS

### 5.1. Шрифты и текст
* `font-family` — семейство шрифтов;
* `font-size` — размер шрифта;
* `color` — цвет текста;
* `text-align` — выравнивание текста;
* `line-height` — межстрочный интервал.

**Пример:**
```css
body {
  font-family: 'Arial', sans-serif;
  font-size: 16px;
  line-height: 1.5;
  color: #333;
}
```

### 5.2. Размеры и отступы
* `width`, `height` — размеры элемента;
* `margin` — внешние отступы;
* `padding` — внутренние отступы;
* `border` — рамка.

**Пример:**
```css
.container {
  width: 960px;
  margin: 0 auto; /* центрирование */
  padding: 20px;
  border: 1px solid #ccc;
}
```

### 5.3. Позиционирование
* `position` — тип позиционирования (`static`, `relative`, `absolute`, `fixed`, `sticky`);
* `display` — способ отображения (`block`, `inline`, `inline-block`, `flex`, `grid`).

**Пример:**
```css
.header {
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
}

.nav {
  display: flex;
  justify-content: space-between;
}
```

### 5.4. Цвета и фон
* `background-color` — цвет фона;
* `background-image` — фоновое изображение;
* `opacity` — прозрачность.

**Пример:**
```css
.hero {
  background-color: #f0f0f0;
  background-image: url('bg.jpg');
  opacity: 0.9;
}
```

## 6. Каскадность и наследование

**Каскадность** — принцип, согласно которому стили применяются в определённом порядке:
1. стили браузера;
2. стили пользователя;
3. стили автора (ваши стили);
4. inline‑стили;
5. `!important`.

**Наследование** — некоторые свойства (шрифты, цвета) передаются от родительских элементов к дочерним.

## 7. Адаптивный дизайн и медиа‑запросы

**Медиа‑запросы** позволяют применять стили в зависимости от параметров устройства.

**Синтаксис:**
```css
@media (условие) {
  /* стили */
}
```

**Примеры:**
```css
/* Стили для экранов шириной до 768 px */
@media (max-width: 768px) {
  .sidebar { display: none; }
}

/* Стили для экранов шириной от 1024 px */
@media (min-width: 1024px) {
  .container { width: 980px; }
}
```

## 8. Методологии организации CSS

### 8.1. BEM (Block Element Modifier)

Структура имён классов:
* блок: `.menu`;
* элемент: `.menu__item`;
* модификатор: `.menu--dark`.

### 8.2. SMACSS (Scalable and Modular Architecture for CSS)

Разделение стилей на категории:
* базовые;
* макет;
* модули;
* состояния;
* темы.

## 9. Практические примеры

### Пример 1: простая кнопка
```css
.btn {
  display: inline-block;
  padding: 12px 24px;
  background-color: #007bff;
  color: white;
  text-decoration: none;
  border-radius: 4px;
  transition: background-color 0.3s;
}

.btn:hover {
  background-color: #0056b3;
}
```

### Пример 2: адаптивная навигация
```css
.nav {
  display: flex;
  list-style: none;
  padding: 0;
}

.nav-item {
  margin-right: 20px;
}

@media (max-width: 768px) {
  .nav {
    flex-direction: column;
  }
  .nav-item {
    margin-right: 0;
    margin-bottom: 10px;
  }
}
```

## 10. Лучшие практики использования CSS

1. **Используйте внешние файлы стилей** для разделения контента и представления.
2. **Организуйте код** — группируйте связанные стили, добавляйте комментарии.
3. **Применяйте методологию** (BEM, SMACSS) для структурирования классов.
4. **Оптимизируйте для производительности** — минимизируйте количество HTTP‑запросов, используйте спрайты.
5. **Тестируйте в разных браузерах** — проверяйте отображение в Chrome, Firefox, Safari, Edge.
6. **Используйте препроцессоры** (SASS, LESS) для сложных проектов.
7. **Следите за специфичностью** — избегайте чрезмерного использования `!important` и ID‑селекторов.
8. **Делайте код читаемым** — используйте понятные имена классов, оставляйте комментарии.

## Заключение

CSS — мощный инструмент для создания привлекательных и функциональных веб‑сайтов. Освоение основ CSS и лучших практик позволит вам:
* создавать визуально привлекательные интерфейсы;
* обеспечивать адаптивность под разные устройства;
* улучшать пользовательский опыт;
* оптимизировать производительность сайта.

Регулярно обновляйте свои знания о возможностях CSS, так как язык постоянно развивается и пополняется новыми свойствами и функциями.
