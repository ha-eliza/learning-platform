**Цель работы:** Приобретение практических навыков сквозного проектирования цифровых продуктов, включающего планирование жизненного цикла, аудит юзабилити, разработку UX/UI-концепции и создание интерактивного высокодетализированного прототипа веб-приложения.

---

## 📝 Задание к выполнению
Выполните комплексный проект по проектированию интерфейса многостраничного веб-приложения или сервиса на самостоятельную тему (например: «Личный кабинет студента», «Панель администратора интернет-магазина» или «Сервис онлайн-записи к врачу»).
В рамках объединенной работы обязательно реализуйте следующие 4 блока:

### Блок 1. Планирование и жизненный цикл проекта (Управление)
* Постройте **календарный план-график** (диаграмму Ганта или таймлайн) проекта, разбив разработку на 6 ключевых этапов (аналитика, проектирование, дизайн, верстка, тестирование, запуск).
* Распределите роли в команде и составьте **матрицу рисков** (3–4 возможных технологических или организационных риска и пути их минимизации).

### Блок 2. Юзабилити-анализ референсов (Аналитика)
* Выберите любой существующий популярный сайт-аналог из вашей предметной области и проведите его **экспресс-аудит**.
* Найдите и зафиксируйте (с помощью скриншотов с пометками) минимум **3 юзабилити-ошибки** (например, путаная навигация, скрытые кнопки, плохой контраст) и напишите рекомендации по их исправлению.

### Блок 3. Проектирование взаимодействия и визуальный стиль (UX/UI Design)
* Опишите одного ключевого персонажа (целевого пользователя) и составьте схему **User Flow** (путь пользователя на сайте для достижения конкретной цели).
* Создайте **базовый UI Kit (стайл-гайд)**: выберите цветовую палитру (основной, вторичный, фоновый цвета), шрифтовые пары для заголовков и текста, а также спроектируйте интерактивные элементы (кнопки, поля ввода) в 3 состояниях (*default, hover, active*).

### Блок 4. Интерактивное прототипирование (Реализация)
* На основе UI Kit соберите в среде Figma (или аналоге) связанную сетку экранов (не менее **4 уникальных страниц** или состояний интерфейса).
* Используйте **компонентный подход** для всех повторяющихся элементов (шапка, подвал, карточки, инпуты).
* Настройте **интерактивные связи (Prototyping)**: сделайте кликабельным главное меню, кнопки отправки форм и анимацию появления всплывающих окон (модалок). Подготовьте проект к демонстрации в режиме презентации.

## 📥 Как прикрепить и сдать работу
Вы можете сдать готовую работу двумя способами: в виде архивного файла или через систему контроля версий.

### Вариант 1. Отправка архивом
1. Сохраните готовое решение.
2. Поместите файл в `ZIP`-архив.
4. Перетащите ваш ZIP-архив в окно загрузчика и нажмите **«Отправить»**.

---

### Вариант 2. Сдача через репозиторий Git
Использование Git — это стандарт современной разработки. Для сдачи работы выполните следующие шаги:

#### Шаг 1. Подготовка локальной папки
Создайте на компьютере отдельную папку для практических работ (например, `web-practics`). Внутри нее создайте папку `task-n`(n - номер задания) и сохраните туда ваше решение.

#### Шаг 2. Инициализация репозитория
Откройте терминал (или Git Bash) в папке проекта и выполните команды:
```bash
# Инициализируем Git в вашей папке
git init

# Добавляем все файлы под контроль версий
git add .

# Делаем первый коммит (фиксацию изменений)
git commit -m "feat: add technical specification for web-site"
```

#### Шаг 3. Создание удаленного репозитория
1. Зайдите на свой аккаунт [GitHub](https://github.com) или [GitLab](https://gitlab.com).
2. Нажмите кнопку **New repository** (Новый репозиторий).
3. Введите имя репозитория (например, `my-web-course`) и выберите тип **Public** (Публичный).
4. Нажмите **Create repository**.

#### Шаг 4. Связывание и отправка кода в облако
Скопируйте ссылку на ваш созданный удаленный репозиторий и вставьте в терминал:
```bash
# Привязываем локальный Git к облаку (замените URL на свой!)
git remote add origin https://github.com

# Переименовываем главную ветку в main
git branch -M main

# Отправляем файлы на сервер
git push -u origin main
```

#### Шаг 5. Отправка ссылки преподавателю
1. Скопируйте итоговую ссылку на ваш публичный репозиторий из адресной строки браузера.
2. В текстовое поле **«Комментарий»** вставьте скопированную ссылку на Git.
3. В нашей системе нажмите кнопку **«Отправить»** под этим заданием.
