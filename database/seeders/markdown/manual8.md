**Вёрстка** — процесс размещения элементов на веб‑странице согласно дизайн‑макету с помощью HTML и CSS.

## Основные этапы вёрстки

1. **Анализ макета** — изучение дизайна, выделение блоков и элементов.
2. **Создание HTML‑структуры** — разметка контента с помощью семантических тегов HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>` и т. д.).
3. **Базовое оформление через CSS** — сброс стилей, настройка типографики, подключение шрифтов.
4. **Позиционирование элементов** — выбор метода вёрстки (float, Flexbox, Grid) и размещение блоков.
5. **Адаптация под устройства** — медиа‑запросы, отзывчивые изображения, гибкие сетки.
6. **Тестирование** — проверка в разных браузерах и на разных экранах (мобильные, планшеты, десктопы).

## Методы вёрстки

* **Табличная** (устаревшая) — через `<table>`; подходит только для табличных данных, не для структуры страницы.
* **Float** — с использованием `float` и `clear`; требует аккуратной работы с потоками и очисткой.
* **Flexbox** — одномерная вёрстка (строка или столбец); идеален для навигаций, карточек, центрирования.
* **Grid** — двумерная вёрстка (строки и столбцы одновременно); подходит для сложных макетов и сеток.
* **Позиционирование** (`position: absolute`, `relative`, `fixed`, `sticky`) — для особых случаев (выпадающие меню, шапки и т. п.).

## Ключевые технологии и инструменты

* **HTML5** — семантическая разметка.
* **CSS3** — стили, Flexbox, Grid, анимации, переменные, медиа‑запросы.
* **БЭМ (BEM)** — методология именования классов (`block__element--modifier`) для структурирования кода.
* **Препроцессоры** (SASS/SCSS) — переменные, миксины, вложенность.
* **Постпроцессоры** (Autoprefixer) — автоматическая расстановка вендорных префиксов.
* **Сборщики** (Webpack, Vite) — автоматизация сборки проекта.
* **Фреймворки** (Bootstrap, Tailwind CSS) — готовые компоненты и утилиты.

## Принципы качественной вёрстки

* **Семантика** — использование тегов по назначению (`<nav>` для навигации, `<article>` для статей и т. д.).
* **Адаптивность** — корректное отображение на любых экранах.
* **Кроссбраузерность** — одинаковая работа в Chrome, Firefox, Safari, Edge и др.
* **Доступность (a11y)** — поддержка скринридеров, клавиатурной навигации, контрастности.
* **Производительность** — оптимизация изображений, минимизация HTTP‑запросов, ленивая загрузка.
* **Поддержка** — чистый и структурированный код, комментарии при необходимости.

## Краткий чек‑лист проверки вёрстки

* [ ] Семантическая HTML‑разметка.
* [ ] Корректное отображение на мобильных устройствах.
* [ ] Отсутствие горизонтальной прокрутки на узких экранах.
* [ ] Читаемый текст (контрастность ≥ 4.5:1).
* [ ] Все интерактивные элементы доступны с клавиатуры.
* [ ] Изображения имеют атрибут `alt`.
* [ ] Нет критических ошибок в инструментах разработчика (DevTools).
* [ ] Быстрая загрузка (оптимизированные ресурсы).

---

**Итог:** качественная вёрстка — это сочетание семантики, адаптивности, доступности и производительности. Начинайте с HTML, оформляйте через CSS, тестируйте на реальных устройствах и браузерах.
