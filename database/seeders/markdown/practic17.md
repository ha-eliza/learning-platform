**Цель работы:** Приобретение практических навыков адаптивной верстки (Responsive Web Design) и оптимизации интерфейса веб-сайта для корректного отображения и удобного использования на экранах планшетов и смартфонов.

---

## 📝 Задание к выполнению
Выполните полную адаптацию ранее созданного десктопного макета веб-сайта (или готовой веб-страницы) под мобильные экраны, используя технологии медиазапросов CSS3.
В рамках объединенной работы обязательно реализуйте следующие 2 блока:

### Блок 1. Адаптация под планшетные устройства (Medium screens: 768px – 1024px)
* Настройте метатег `<meta name="viewport" content="width=device-width, initial-scale=1.0">` в HTML-документе.
* Напишите медиазапросы для планшетного разрешения (например, `@media (max-width: 1024px)`).
* Перестройте крупные блоки: уменьшите ширину боковых панелей (сайдбаров) или переведите трехколоночную сетку в двухколоночную.
* Адаптируйте типографику (уменьшите размеры шрифтов заголовков) и оптимизируйте отступы (`margin`, `padding`), чтобы избавиться от горизонтальной прокрутки.

### Блок 2. Адаптация под смартфоны (Small screens: менее 768px)
* Напишите медиазапросы для мобильного разрешения (например, `@media (max-width: 767px)` и `@media (max-width: 480px)`).
* Трансформируйте макет в строгую **одноколоночную структуру** — все элементы (карточки, секции) должны последовательно располагаться друг под другом.
* Скройте классическое навигационное меню шапки и реализуйте вместо него адаптивное **скрытое меню («бургер»)**.
* Увеличьте кликабельные зоны элементов (кнопки, ссылки, иконки) минимум до 44x44 пикселей для удобства нажатия на тач-экранах.
* Проверьте работу всех форм ввода (инпутов) — при фокусе на мобильном устройстве интерфейс не должен ломаться.

### Вариант 2. Сдача через репозиторий Git
Использование Git — это стандарт современной разработки. Для сдачи работы выполните следующие шаги:

#### Шаг 1. Подготовка локальной папки
Создайте на компьютере отдельную папку для практических работ (например, `web-practics`). Внутри нее создайте папку `task-n`(n - номер задания) и сохраните туда ваше решение.

#### Шаг 2. Инициализация репозитория
Откройте терминал (или Git Bash) в папке проекта и выполните команды:
```bash
# Инициализируем Git в вашей папке
git init

# Добавляем все файлы под контроль версий
git add .

# Делаем первый коммит (фиксацию изменений)
git commit -m "feat: add technical specification for web-site"
```

#### Шаг 3. Создание удаленного репозитория
1. Зайдите на свой аккаунт [GitHub](https://github.com) или [GitLab](https://gitlab.com).
2. Нажмите кнопку **New repository** (Новый репозиторий).
3. Введите имя репозитория (например, `my-web-course`) и выберите тип **Public** (Публичный).
4. Нажмите **Create repository**.

#### Шаг 4. Связывание и отправка кода в облако
Скопируйте ссылку на ваш созданный удаленный репозиторий и вставьте в терминал:
```bash
# Привязываем локальный Git к облаку (замените URL на свой!)
git remote add origin https://github.com

# Переименовываем главную ветку в main
git branch -M main

# Отправляем файлы на сервер
git push -u origin main
```

#### Шаг 5. Отправка ссылки преподавателю
1. Скопируйте итоговую ссылку на ваш публичный репозиторий из адресной строки браузера.
2. В текстовое поле **«Комментарий»** вставьте скопированную ссылку на Git.
3. В нашей системе нажмите кнопку **«Отправить»** под этим заданием.
