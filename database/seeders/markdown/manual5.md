**Веб‑стандарты** — это набор спецификаций и рекомендаций, разработанных консорциумом W3C (World Wide Web Consortium) и другими организациями для обеспечения единообразия и совместимости веб‑технологий.


**Ключевые веб‑стандарты:**
* **HTML** — язык разметки веб‑страниц;
* **CSS** — каскадные таблицы стилей для оформления;
* **ECMAScript (JavaScript)** — язык сценариев;
* **DOM** — объектная модель документа;
* **HTTP** — протокол передачи данных.

**Преимущества соблюдения стандартов:**
* кроссбраузерная совместимость;
* доступность для людей с ограниченными возможностями;
* лучшая индексация поисковыми системами;
* лёгкость поддержки и масштабирования;
* соответствие современным требованиям веба.

## HTML5: новая эра веб‑разработки

**HTML5** — последняя версия стандарта HTML, которая внесла значительные улучшения в структуру и функциональность веб‑страниц.

**Основные нововведения HTML5:**
* семантические элементы;
* нативная поддержка мультимедиа (`<audio>`, `<video>`);
* новые элементы форм;
* API для локального хранения данных;
* улучшенная поддержка графики (`<canvas>`);
* геопозиционирование;
* веб‑сокеты для реального времени.

## Базовая структура HTML5‑документа

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Название страницы</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <!-- содержимое страницы -->
</body>
</html>
```

**Разбор структуры:**

1. **`<!DOCTYPE html>`** — объявление типа документа (HTML5).
2. **`<html lang="ru">`** — корневой элемент с указанием языка.
3. **`<head>`** — секция с метаданными:
   * `<meta charset="UTF-8">` — кодировка;
   * `<meta name="viewport">` — настройки для мобильных устройств;
   * `<title>` — заголовок страницы;
   * `<link>` — подключение внешних ресурсов.
4. **`<body>`** — основное содержимое страницы.

## Семантические элементы HTML5

Семантические элементы улучшают структуру документа и его понимание поисковыми системами и вспомогательными технологиями.

### Основные семантические блоки

* **`<header>`** — шапка страницы или раздела.
* **`<nav>`** — навигационное меню.
* **`<main>`** — основной контент страницы.
* **`<article>`** — самодостаточный контент (статья, новость).
* **`<section>`** — тематическая группировка контента.
* **`<aside>`** — побочный контент (боковая панель).
* **`<footer>`** — подвал страницы или раздела.

**Пример использования:**
```html
<header>
  <h1>Мой сайт</h1>
  <nav>
    <ul>
      <li><a href="/">Главная</a></li>
      <li><a href="/about">О нас</a></li>
    </ul>
  </nav>
</header>

<main>
  <article>
    <h2>Заголовок статьи</h2>
    <p>Текст статьи...</p>
  </article>
</main>

<aside>
  <h3>Полезные ссылки</h3>
  <ul>
    <li><a href="#">Ссылка 1</a></li>
  </ul>
</aside>

<footer>
  <p>&copy; 2026 Мой сайт. Все права защищены.</p>
</footer>
```

## Основные элементы HTML5 и их атрибуты

### Текстовые элементы

* **`<h1>`–`<h6>`** — заголовки разных уровней.
* **`<p>`** — абзац текста.
* **`<a href="URL">`** — гиперссылка.
* **`<strong>`**, **`<em>`** — логическое выделение (жирный, курсив).

### Мультимедиа

* **`<img src="путь" alt="описание">`** — изображение.
* **`<audio>`**, **`<video>`** — аудио и видео.
* **`<source>`** — источник мультимедиа.

### Списки

* **`<ul>`**, **`<ol>`**, **`<li>`** — маркированные и нумерованные списки.
* **`<dl>`, `<dt>`, `<dd>`** — список определений.

### Таблицы

* **`<table>`, `<tr>`, `<td>`, `<th>`** — таблицы.
* **`<thead>`, `<tbody>`, `<tfoot>`** — секции таблицы.

### Формы

* **`<form>`, `<input>`, `<textarea>`, `<button>`** — элементы форм.
* **`<label>`, `<fieldset>`, `<legend>`** — организация форм.

## Важные атрибуты HTML5

### Глобальные атрибуты (работают с любым элементом)

* **`class`** — классы для стилизации.
* **`id`** — уникальный идентификатор.
* **`style`** — встроенные стили.
* **`title`** — всплывающая подсказка.
* **`data-*`** — пользовательские данные.

### Специфичные атрибуты

* **`src`** — источник для изображений, скриптов.
* **`href`** — ссылка для ссылок и стилей.
* **`alt`** — альтернативный текст для изображений.
* **`placeholder`** — подсказка в полях ввода.
* **`required`** — обязательное поле формы.
* **`autofocus`** — фокус при загрузке.

## Поддержка веб‑стандартов браузерами

### Современные браузеры и их движки

* Chrome, Edge — Blink;
* Firefox — Gecko;
* Safari — WebKit.

### Проверка поддержки

**Способы проверки поддержки стандартов:**

1. **Can I use** (caniuse.com) — сервис проверки поддержки функций.
2. **Валидатор W3C** (validator.w3.org) — проверка соответствия стандартам.
3. **Инструменты разработчика браузера** — отладка и тестирование.

### Полифиллы (Polyfills)


Для поддержки старых браузеров используют полифиллы — скрипты, эмулирующие функциональность HTML5:
* Modernizr — определение поддержки функций;
* html5shiv — поддержка семантических элементов в IE8 и ниже;
* Respond.js — поддержка медиа‑запросов в старых IE.

## Лучшие практики использования HTML5

1. **Соблюдайте семантику** — используйте правильные элементы для их назначения.
2. **Делайте контент доступным** — добавляйте `alt` к изображениям, `label` к полям форм.
3. **Используйте UTF‑8** — универсальная кодировка для всех языков.
4. **Оптимизируйте для мобильных** — viewport, адаптивный дизайн.
5. **Проверяйте валидность** — регулярно тестируйте код на соответствие стандартам.
6. **Минимизируйте использование inline‑стилей** — отделяйте структуру от оформления.
7. **Следуйте иерархии заголовков** — `<h1>` только один на страницу, логичная последовательность.

## Пример полной структуры страницы

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <meta name="description" content="Пример страницы HTML5">
  <title>Пример HTML5 страницы</title>
  <link rel="stylesheet" href="styles.css">

  <header>
    <h1>Мой сайт</h1>

        <li><a href="/contact">Контакты</a></li>
      </ul>
    </nav>
  </header>

  <main>
    <article>
      <header>
        <h2>Заголовок статьи</h2>
        <time datetime="2026-05-22">22 мая 2026</time>
      </header>
      <p>Содержание статьи...</p>
    </article>
  </main>

  <aside>
    <section>
      <h3>Популярные статьи</h3>
      <ul>
        <li><a href="#">Статья 1</a></li>
        <li><a href="#">Статья 2</a></li>
      </ul>
    </section>
  </aside>

  <footer>
    <p>&copy; 2026 Мой сайт. Все права защищены.</p>
  </footer>
</body>
</html>
```
