---

## 📝 Задание к выполнению
Разработайте адаптивный лендинг или многостраничный прототип сайта (например: «Сайт конференции», «Лендинг мобильного приложения» или «Страница портфолио») на базе фреймворка Bootstrap 4 без написания пользовательского CSS-кода с нуля.
При создании страницы обязательно реализуйте следующие требования:

1. **Адаптивная сетка (Grid System):** соберите каркас страницы с помощью классов `.container`, `.row` и `.col-*`. Настройте адаптивность колонок (например, `.col-12 .col-md-6 .col-lg-4`), чтобы макет корректно перестраивался на смартфонах, планшетах и мониторах.
2. **Навигационная панель:** интегрируйте стандартный компонент меню (`navbar`), настроив его автоматическое сворачивание в «гамбургер» на мобильных устройствах.
3. **Интерфейсные компоненты:** разместите на странице минимум 3 различных компонента Bootstrap 4 (например: адаптивный слайдер `carousel`, карточки товаров `card`, всплывающие модальные окна `modal` или аккордеон `collapse`).
4. **Классы-утилиты:** выполните всю верстку элементов (кнопки, формы, текстовые блоки), используя встроенные классы для отступов (`p-3`, `mx-auto`), цвета текста и фона (`text-center`, `bg-light`, `btn-primary`).

### Вариант 2. Сдача через репозиторий Git
Использование Git — это стандарт современной разработки. Для сдачи работы выполните следующие шаги:

#### Шаг 1. Подготовка локальной папки
Создайте на компьютере отдельную папку для практических работ (например, `web-practics`). Внутри нее создайте папку `task-n`(n - номер задания) и сохраните туда ваше решение.

#### Шаг 2. Инициализация репозитория
Откройте терминал (или Git Bash) в папке проекта и выполните команды:
```bash
# Инициализируем Git в вашей папке
git init

# Добавляем все файлы под контроль версий
git add .

# Делаем первый коммит (фиксацию изменений)
git commit -m "feat: add technical specification for web-site"
```

#### Шаг 3. Создание удаленного репозитория
1. Зайдите на свой аккаунт [GitHub](https://github.com) или [GitLab](https://gitlab.com).
2. Нажмите кнопку **New repository** (Новый репозиторий).
3. Введите имя репозитория (например, `my-web-course`) и выберите тип **Public** (Публичный).
4. Нажмите **Create repository**.

#### Шаг 4. Связывание и отправка кода в облако
Скопируйте ссылку на ваш созданный удаленный репозиторий и вставьте в терминал:
```bash
# Привязываем локальный Git к облаку (замените URL на свой!)
git remote add origin https://github.com

# Переименовываем главную ветку в main
git branch -M main

# Отправляем файлы на сервер
git push -u origin main
```

#### Шаг 5. Отправка ссылки преподавателю
1. Скопируйте итоговую ссылку на ваш публичный репозиторий из адресной строки браузера.
2. В текстовое поле **«Комментарий»** вставьте скопированную ссылку на Git.
3. В нашей системе нажмите кнопку **«Отправить»** под этим заданием.
