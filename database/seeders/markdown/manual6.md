Селекторы — это шаблоны в CSS, которые позволяют выбирать HTML‑элементы для применения к ним стилей. Грамотное использование селекторов — основа качественной вёрстки и стилизации веб‑страниц.

## Базовые типы селекторов

### 1. Селектор по тегу
Выбирает все элементы с указанным тегом на странице.

**Пример:**
```css
p {
  font-size: 16px;
  line-height: 1.5;
}
```

### 2. Селектор по классу
Выбирает элементы с указанным классом (атрибут `class`). Перед именем класса ставится точка (`.`).

**Пример:**
```css
.highlight {
  background-color: yellow;
  padding: 5px;
}
```

**HTML‑использование:**
```html
<p class="highlight">Этот текст будет подсвечен</p>
```

### 3. Селектор по идентификатору
Выбирает элемент с уникальным идентификатором (атрибут `id`). Перед ID ставится решётка (`"`).

**Пример:**
```css
#main-header {
  color: #333;
  font-size: 24px;
}
```

**Важно:** ID должен быть уникальным на странице.

### 4. Универсальный селектор
Выбирает абсолютно все элементы на странице. Обозначается звёздочкой (`*`).

**Пример (сброс отступов):**
```css
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}
```

### 5. Групповой селектор
Позволяет применить одинаковые стили к нескольким селекторам. Селекторы разделяются запятыми.

**Пример:**
```css
h1, h2, h3 {
  font-family: Arial, sans-serif;
  color: #222;
}
```

## Селекторы атрибутов

Выбирают элементы на основе наличия или значения атрибутов.

### Основные варианты:

* `[attr]` — элементы с атрибутом `attr`;
* `[attr="value"]` — элементы, где `attr` равен `value`;
* `[attr^="value"]` — `attr` начинается с `value`;
* `[attr$="value"]` — `attr` заканчивается на `value`;
* `[attr*="value"]` — `attr` содержит `value`.

**Примеры:**
```css
/* Все ссылки с href */
a[href] {
  text-decoration: none;
}

/* Ссылки, ведущие на внешние ресурсы */
a[href^="http://"] {
  color: blue;
}

/* Поля ввода типа email */
input[type="email"] {
  border: 2px solid #007bff;
}
```

## Комбинаторные селекторы

Позволяют выбирать элементы на основе их расположения относительно других элементов.

### 1. Дочерний селектор (`>`)
Выбирает непосредственных потомков.

```css
ul > li {
  list-style-type: square;
}
```

### 2. Соседний родственный селектор (`+`)
Выбирает элемент, который непосредственно следует за указанным элементом.

```css
h2 + p {
  margin-top: 0;
}
```

### 3. Общий родственный селектор (`~`)
Выбирает все элементы, следующие за указанным элементом на том же уровне вложенности.

```css
h2 ~ p {
  color: gray;
}
```

### 4. Контекстный (потомковый) селектор (пробел)
Выбирает всех потомков указанного элемента.

```css
nav a {
  color: white;
  text-decoration: none;
}
```

## Псевдоклассы

Селекторы, описывающие особое состояние элемента.

### Часто используемые псевдоклассы:

* `:hover` — при наведении курсора;
* `:focus` — когда элемент в фокусе;
* `:active` — в момент нажатия;
* `:visited` — посещённые ссылки;
* `:first-child` — первый дочерний элемент;
* `:last-child` — последний дочерний элемент;
* `:nth-child(n)` — n‑й дочерний элемент.

**Примеры:**
```css
button:hover {
  background-color: #0056b3;
}

input:focus {
  border-color: #007bff;
  outline: none;
}

li:nth-child(even) {
  background-color: #f9f9f9;
}
```

## Псевдоэлементы

Создают виртуальные элементы для стилизации частей содержимого.

### Основные псевдоэлементы:

* `::before` — вставка перед содержимым;
* `::after` — вставка после содержимого;
* `::first-line` — первая строка текста;
* `::first-letter` — первая буква текста.

**Пример использования `::before`:**
```css
.warning::before {
  content: "⚠️ ";
  font-weight: bold;
}
```

**HTML:**
```html
<div class="warning">Внимание: важная информация!</div>
```

Результат: «⚠️ Внимание: важная информация!»

## Специфичность селекторов

Специфичность определяет, какой стиль будет применён, если к элементу относятся несколько правил. Порядок приоритета (от высшего к низшему):

1. Стили с `!important`.
2. Селекторы по ID (`"`).
3. Селекторы по классу (`.`), атрибуту (`[attr]`) и псевдоклассы (`:hover`).
4. Селекторы по тегу и псевдоэлементы (`::before`).
5. Универсальный селектор (`*`).

**Пример расчёта специфичности:**
* `#main .content p` → 102 (1 ID + 1 класс + 1 тег);
* `.sidebar ul li` → 022 (2 класса + 2 тега);
* `div p` → 002 (2 тега).

## Практические рекомендации

### Лучшие практики использования селекторов:


1. **Избегайте чрезмерного использования ID** — они имеют высокую специфичность и усложняют переопределение стилей.
2. **Предпочитайте классы** для стилизации — они более гибкие и переиспользуемые.
3. **Не используйте слишком длинные цепочки селекторов** — это снижает производительность и усложняет поддержку.
4. **Используйте семантические имена классов** (например, `.card`, `.nav-link`), а не стилистические (`.red-text`).
5. **Группируйте общие стили** для сокращения объёма кода.
6. **Тестируйте в разных браузерах** — некоторые псевдоклассы и селекторы атрибутов могут работать неодинаково.

### Пример хорошей практики:
```css
/* Хорошо: короткий, понятный селектор */
.card {
  padding: 20px;
  border-radius: 8px;
}

.card-title {
  font-size: 18px;
  margin-bottom: 10px;
}

/* Плохо: слишком специфичный */
div#main-container > section.card:first-child > h2.title {
  /* ... */
}
```

## Заключение

Понимание и грамотное применение селекторов HTML5 и CSS — ключевой навык веб‑разработчика. Это позволяет:
* создавать структурированные и поддерживаемые стили;
* обеспечивать кроссбраузерную совместимость;
* оптимизировать производительность страницы;
* реализовывать сложные интерактивные эффекты;
* следовать современным стандартам веб‑разработки.

Регулярно обновляйте знания о новых селекторах и псевдоклассах — стандарты развиваются, и появляются новые возможности для улучшения пользовательского опыта и качества кода.
