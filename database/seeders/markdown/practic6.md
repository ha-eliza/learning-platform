**Цель работы:** Приобретение практических навыков проектирования и реализации сложных трехколоночных макетов веб-страниц с использованием современной технологии CSS Grid Layout и двухколоночных макетов CSS Flex Layout.

---

## 📝 Задание к выполнению
Разработайте веб-страницу с классической трехколоночной структурой на самостоятельную тему (например: «Главная страница портала СМИ», «Панель управления / Dashboard» или «Каталог товаров с двумя боковыми панелями»).
При создании макета обязательно реализуйте следующие требования:

1. **Грид-каркас:** объявите главный контейнер сетки (`display: grid`) и задайте три колонки (например, левый сайдбар, основной контент, правый сайдбар).
2. **Гибкие размеры:** используйте современную единицу измерения `fr` (fractional unit) для создания адаптивной центральной колонки и фиксированные размеры (px, rem) для боковых панелей.
3. **Компоновка страницы:** разместите на странице 5 обязательных зон: шапку (header), левую панель навигации (aside), центральный контент (main), правую панель виджетов (aside) и подвал (footer).
4. **Выравнивание и отступы:** настройте аккуратные промежутки между колонками с помощью `gap` и выровняйте элементы по сетке.
5. **Семантическая разметка:** используйте HTML5-теги (`<header>`, `<main>`, `<aside>`, `<footer>`) для корректной структуры документа.
6. **Двухколоночный каркас:** настройте сетку макета с помощью CSS-свойств (`display: flex` или `display: grid`).
7. **Пропорции и размеры:** задайте фиксированную или адаптивную ширину для боковой панели (sidebar) и гибкую ширину для основной колонки.
8. **Прижмите подвал:** настройте стили так, чтобы подвал сайта (`footer`) всегда находился внизу страницы, независимо от объема контента.

### Вариант 2. Сдача через репозиторий Git
Использование Git — это стандарт современной разработки. Для сдачи работы выполните следующие шаги:

#### Шаг 1. Подготовка локальной папки
Создайте на компьютере отдельную папку для практических работ (например, `web-practics`). Внутри нее создайте папку `task-n`(n - номер задания) и сохраните туда ваше решение.

#### Шаг 2. Инициализация репозитория
Откройте терминал (или Git Bash) в папке проекта и выполните команды:
```bash
# Инициализируем Git в вашей папке
git init

# Добавляем все файлы под контроль версий
git add .

# Делаем первый коммит (фиксацию изменений)
git commit -m "feat: add technical specification for web-site"
```

#### Шаг 3. Создание удаленного репозитория
1. Зайдите на свой аккаунт [GitHub](https://github.com) или [GitLab](https://gitlab.com).
2. Нажмите кнопку **New repository** (Новый репозиторий).
3. Введите имя репозитория (например, `my-web-course`) и выберите тип **Public** (Публичный).
4. Нажмите **Create repository**.

#### Шаг 4. Связывание и отправка кода в облако
Скопируйте ссылку на ваш созданный удаленный репозиторий и вставьте в терминал:
```bash
# Привязываем локальный Git к облаку (замените URL на свой!)
git remote add origin https://github.com

# Переименовываем главную ветку в main
git branch -M main

# Отправляем файлы на сервер
git push -u origin main
```

#### Шаг 5. Отправка ссылки преподавателю
1. Скопируйте итоговую ссылку на ваш публичный репозиторий из адресной строки браузера.
2. В текстовое поле **«Комментарий»** вставьте скопированную ссылку на Git.
3. В нашей системе нажмите кнопку **«Отправить»** под этим заданием.
