**JavaScript (JS)** — это высокоуровневый, динамический, интерпретируемый язык программирования, который в основном используется для создания интерактивных элементов на веб‑страницах.
​
​
**Ключевые характеристики:**
* **Динамическая типизация** — типы переменных определяются во время выполнения.
* **Интерпретируемый** — не требует компиляции перед выполнением.
* **Мультипарадигменный** — поддерживает процедурное, объектно‑ориентированное и функциональное программирование.
* **Кроссплатформенный** — работает в браузерах, на серверах (Node.js), в мобильных приложениях.
​
## История и развитие
​
* **1995** — создан Бренданом Эйхом в Netscape под названием LiveScript, позже переименован в JavaScript.
* **1997** — стандартизирован как ECMAScript (ES1).
* **2009** — выход ES5 с важными улучшениями.
* **2015** — революционный ES6 (ES2015) с классами, стрелочными функциями и т. д.
* **С 2015** — ежегодные обновления стандарта (ES2016, ES2017 и т. д.).
​
## Где используется JavaScript
​
​
* **Веб‑разработка:**
   * фронтенд (интерактивность на страницах);
   * бэкенд (Node.js);
   * мобильные приложения (React Native, Ionic);
   * десктопные приложения (Electron).
* **Автоматизация задач** (скрипты для браузеров, расширения).
* **Игры** (с использованием Canvas, WebGL).
* **Интернет вещей (IoT)** (платформы типа Johnny‑Five).
​
## Основы синтаксиса
​
### Переменные
​
```javascript
let name = "Анна";        // изменяемая переменная
const PI = 3.14;       // константа, нельзя изменить
var oldVar = "устаревшее"; // старый способ (не рекомендуется)
```
​
### Типы данных
​
* `string` — строки (`"текст"`);
* `number` — числа (`42`, `3.14`);
* `boolean` — логические значения (`true`, `false`);
* `null` — «пустое» значение;
* `undefined` — неинициализированная переменная;
* `object` — объекты, массивы, функции;
* `symbol` — уникальные идентификаторы (ES6).
​
### Условные операторы
​
```javascript
if (age >= 18) {
  console.log("Доступ разрешён");
} else {
  console.log("Доступ запрещён");
}
```
​
### Циклы
​
```javascript
for (let i = 0; i < 5; i++) {
  console.log(i);
}
​
while (condition) {
  // код
}
```
​
### Функции
​
```javascript
function greet(name) {
  return `Привет, ${name}!`;
}
​
// Стрелочная функция (ES6)
const sum = (a, b) => a + b;
```
​
### Объекты
​
```javascript
const user = {
  name: "Иван",
  age: 30,
  greet() {
    console.log(`Привет, я ${this.name}`);
  }
};
```
​
### Массивы
​
```javascript
const fruits = ["яблоко", "банан", "апельсин"];
fruits.push("груша"); // добавить элемент
```

## Современные возможности (ES6+)
​
### Классы
​
```javascript
class Animal {
  constructor(name) {
    this.name = name;
  }
  speak() {
    console.log(`${this.name} издаёт звук.`);
  }
}
```
​
### Деструктуризация
​
```javascript
const person = { name: "Мария", age: 25 };
const { name, age } = person;
```
​
### Промисы и async/await
​
```javascript
async function fetchData() {
  try {
    const response = await fetch('/api/data');
    const data = await response.json();
    return data;
  } catch (error) {
    console.error('Ошибка:', error);
  }
}
```
​
### Модули
​
```javascript
// export
export const API_URL = 'https://api.example.com';
​
// import
import { API_URL } from './config.js';
```

## Работа с DOM (Document Object Model)
​
JavaScript позволяет управлять элементами веб‑страницы:
​
```javascript
// Получить элемент
const button = document.getElementById('myButton');
​
// Изменить стиль
button.style.color = 'red';
​
// Добавить обработчик события
button.addEventListener('click', () => {
  alert('Кнопка нажата!');
});
​
// Создать новый элемент
const newDiv = document.createElement('div');
newDiv.textContent = 'Новый элемент';
document.body.appendChild(newDiv);
```
​
## Асинхронность в JavaScript
​
JavaScript использует **событийный цикл (event loop)** для обработки асинхронных операций:
​
* **Callback‑функции** — функции, вызываемые после завершения операции.
* **Промисы (Promises)** — объекты, представляющие результат асинхронной операции.
* **Async/await** — синтаксический сахар для работы с промисами.
​
**Пример:**
```javascript
fetch('https://api.example.com/users')
  .then(response => response.json())
  .then(users => console.log(users))
  .catch(error => console.error('Ошибка:', error));
```

## Лучшие практики программирования
​
1. **Используйте `let` и `const`** вместо `var`.
2. **Соблюдайте единый стиль кода** (используйте ESLint, Prettier).
3. **Разделяйте код на модули**.
4. **Обрабатывайте ошибки** с помощью `try...catch`.
5. **Оптимизируйте производительность**:
   * избегайте частых операций с DOM;
   * используйте делегирование событий;
   * минимизируйте перерисовки.
6. **Тестируйте код** (Jest, Mocha).
7. **Документируйте функции** (JSDoc).

## Безопасность
​
**Типичные угрозы:**
* XSS (межсайтовый скриптинг) — внедрение вредоносного кода.
* CSRF (подделка межсайтовых запросов) — выполнение действий от имени пользователя.
* утечки данных через API.
​
**Меры защиты:**
* санируйте пользовательский ввод;
* используйте HTTPS;
* применяйте CORS‑политики;
* валидируйте данные на сервере.
