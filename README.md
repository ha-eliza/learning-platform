# Source.Library — Информационная система учебно-методического сайта

Веб-приложение представляет собой интерактивную образовательную платформу, разработанную в рамках дипломного проекта.

## 🛠 Стек технологий

*   **Backend:** фреймворк Laravel (PHP 8.4), Eloquent ORM, СУБД MySQL.
*   **Frontend:** библиотека React, строго типизированный язык TypeScript.
*   **Архитектура SPA:** мост Inertia.js для обмена данными в формате JSON без полной перезагрузки страниц сайта.
*   **Стилизация и UI-компоненты:** атомарный CSS-фреймворк Tailwind CSS, библиотека компонентов Ant Design и пакет иконок `@ant-design/icons`.
*   **Графические эффекты:** анимационная интерактивная 3D-сетка на базе библиотеки Vanta.js.

## 💻 Ключевой функционал

1.  **Эргономичная «Библиотека»:** Список лекций и практикумов с модулями умного поиска, тегирования и фильтрации данных.
2.  **Личный кабинет студента:** Интерактивная таблица с выводом динамических статусов проверок («На проверке», «На доработке», «Сдано») и встроенным триггером оперативного исправления решений.
3.  **Панель администрирования (Преподаватель):** Полноценное CRUD-управление контентом, включая встроенный визуальный Markdown-редактор, модальное окно оценки работ.

## 🚀 Инструкция по локальному развертыванию

1.  **Клонирование репозитория:**
    ```bash
    git clone https://github.com
    cd source-library
    ```
2.  **Настройка бэкенда (Laravel):**
    ```bash
    composer install
    cp .env.example .env
    php artisan key:generate
    ```
    *Настройте подключение к базе данных MySQL в созданном файле `.env`.*
3.  **Развертывание базы данных:**
    ```bash
    php artisan migrate --seed
    ```
4.  **Установка и сборка фронтенда (React):**
    ```bash
    npm install
    npm run build
    ```
5.  **Запуск локального сервера:**
    ```bash
    php artisan serve
    ```
